about me

I'm Tobi Adedoyin, a full-stack web developer interested in building reliable, user-focused web applications. I work across frontend development and backend engineering, using HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

My development experience includes building responsive interfaces, creating and testing REST APIs, integrating databases, debugging existing code, and collaborating through Git and GitHub. I have also contributed to open-source projects, working on areas such as application features, test coverage, API behaviour, and code quality.

I hold a B.Sc. (Ed.) in Physics from Aliko Dangote University of Science and Technology, graduating with a Second Class Upper (2:1). My academic background strengthened my analytical and problem-solving approach, which I bring into software development.

I'm continuing to improve my engineering skills through practical projects and collaborative work. I'm interested in opportunities where I can build, learn, and contribute as a web developer.

Tools & Technologies

Frontend: HTML5, CSS3, JavaScript, React, Next.js, and TypeScript.

Backend: Node.js, Express.js, REST APIs, authentication, and API integration.

Database: MongoDB and MongoDB Atlas, with Mongoose for data modelling.

Testing & workflow: Vitest, automated testing, npm, Git, and GitHub.

Deployment: Netlify and practical deployment troubleshooting.
